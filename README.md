# DeltaMap 三角洲战术地图

一款轻量化的《三角洲行动》全面战场地图编辑工具。支持官方底图、据点边界、自由绘图、载具与固定工事标记、本地自动保存以及 PNG/JSON 导入导出。

当前版本：**v1.2.1**

JDI出品，欢迎各路大神加入JDI。

项目仓库：[onlyxiaohuang/deltamap](https://github.com/onlyxiaohuang/deltamap)

多人协作、房间聊天和临时公网开房属于私有维护的 DeltaMap Pro，不包含在本公开基础版中。

觉得项目有用，欢迎打开仓库右上角点一个 **Star**，让更多玩家找到这个工具。

## 一键下载

普通玩家不需要安装开发环境：

1. 打开 [GitHub Releases](https://github.com/onlyxiaohuang/deltamap/releases)。
2. 展开最新版本的 `Assets`。
3. 下载 `DeltaMap.exe`。
4. 双击 `DeltaMap.exe`，地图会以独立窗口打开。

EXE 已包含全部地图、边界、图标、脚本和样式，不需要另外下载资源文件。首次启动会把内置资源释放到 `%LOCALAPPDATA%\DeltaMap\app`，后续启动会直接复用。

> Windows SmartScreen 可能提示“Windows 已保护你的电脑”。这是个人开源项目未购买代码签名证书导致的。确认文件来自本仓库 Release 后，可选择“更多信息” -> “仍要运行”。

## 功能

- 13 张 PC 全面战场官方地图
- 攻防与占领模式切换
- 官方据点、基地、载具、补给、固定武器和地图装置图层
- 战区边界、阶段边界和据点边界
- 画笔、直线、箭头、矩形、圆形、文字和标记点
- 两点水平测距工具，按游戏内实测校准比例显示米数
- 自由圈定地图地名范围，名称和范围支持逐条或批量显示/关闭
- 麦晓雯数据飞刀 `50m + 15m` 范围和回响大招 `75m / 120°` 扇形
- 可自由放置、着色和拖动的人员、载具与固定工事
- 浏览器本地自动保存
- 撤销、重做和清空
- PNG 图片与 JSON 战术方案导入导出
- 完整离线资源

## 一键生成 EXE

仓库根目录提供了 [`build-exe.ps1`](build-exe.ps1)。它使用 Windows 自带的 .NET Framework C# 编译器，不要求安装 Visual Studio、Node.js 或 Electron。

在项目目录空白处按住 `Shift` 并右键打开 PowerShell，然后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build-exe.ps1
```

也可以直接右键 `build-exe.ps1`，选择“使用 PowerShell 运行”。生成结果位于：

```text
release\DeltaMap.exe
```

脚本会自动收集全部本地资源、生成内置压缩包、编译启动器，并把所有内容嵌入单个 EXE。打包完成后会自动删除临时文件。

## 网页版运行

不需要 EXE 时，也可以直接双击 `index.html` 使用。所有运行资源均已本地化。

## 数据说明

### 地图比例尺

官方地图数据的 `info.width`、`info.height`、`centerX`、`centerY` 和 `rotate` 用于把游戏世界坐标映射到地图。初始换算随后使用游戏内已知水平距离进行实测校准，各地图保留官方数据中的长宽比例。

断轨校准示例：同一条水平线段在游戏内为 `13m`，旧版 DeltaMap 显示 `6.5m`，因此 v1.1.0 将米制换算统一乘以 `2`。断轨由 `700m x 700m` 调整为 `1400m x 1400m`，其他地图按相同倍率换算。该结果来自当前实测样本，后续可通过更多横向、纵向和斜向基准继续修正。

选择左侧带“水平”标识的尺子按钮，在地图任意两点之间拖动即可生成测距线。结果是地图平面的二维直线距离，不包含地形高差、三维斜距、道路曲线或建筑楼层高度。

### 地名标注

选择工具栏的地名工具，按住鼠标沿区域边界自由描绘，松开后输入名称。每条地名的范围与名称可以独立显示或关闭，也可以在左侧“图层”页面的“地图地名”区域批量关闭全部范围、全部名称或全部地名。

地名按地图保存在战术项目的 `callouts` 字段中，并随本地自动保存和 JSON 导入导出保留。字段名保持不变是为了兼容旧 JSON，不会清空升级前已经圈定的示例。旧版圆形范围也可以继续显示。

### 干员道具

- **麦晓雯 · 数据飞刀**：点击地图放置，显示 `50m` 内圈与 `65m` 外圈（`50m + 15m`）。
- **回响 · 大招**：在地图上按住并向目标方向拖动，显示半径 `75m`、夹角 `120°` 的扇形。

道具范围使用当前地图的水平米制比例，可选择颜色，并支持拖动、删除、撤销以及 PNG/JSON 导出。当前使用本地图形标识；找到可验证来源的官方透明技能图标后可以直接替换显示资源，不影响已保存的道具数据。
