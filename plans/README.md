# DeltaMap 战术复盘格式

本目录中的方案可通过 DeltaMap 顶部“导出”菜单中的“导入战术文件”直接打开。

文件继续使用 DeltaMap `version: 1` 项目结构，并增加 `strategy` 元数据：

- `schema`：战术扩展格式版本。
- `source`：复盘来源视频。
- `match`、`map`、`round`：比赛、地图和回合。
- `teams`：双方名称、攻守和标记颜色。
- `phases`：各阶段目标与战术思路。
- `legend`：图上颜色含义。
- `confidence`：复盘依据及限制。

颜色约定：SEA 使用蓝色 `#42a5ff`，JDI 使用橙色 `#ffb43b`，白色用于中立阶段说明。

视频为导播视角且无公开字幕，方案依据全局航拍、阶段进度和交火重心进行宏观复盘，不代表战队原始战术文件或逐名选手精确走位。
